## Review questions

1. What does ink += 15 do?
2. Which values are booleans?
3. Can a variable declared with let be reassigned?

5. What happens when you run ink -= 30?

7. What does ink = ink + 10 do?
8. A player starts with 60 ink, collects 20, and spends 45. How much remains?

2. true and false, without quotation marks.
3. Yes.
4. String.
5. Subtracts 30 from the current value and stores the result.
6. The first and fourth declarations.
7. Adds 10 to the current value and stores the result.
8. 35.
9. let hasWeapon = false;
