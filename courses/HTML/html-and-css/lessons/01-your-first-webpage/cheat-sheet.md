# Lesson 1 Cheat Sheet: Your first webpage

## Basic page structure

    <!DOCTYPE html>
    <html>
      <head>
        <title>Page title</title>
      </head>
      <body>
        <h1>Main heading</h1>
        <p>A paragraph.</p>
      </body>
    </html>

## Common parts

| Code | Purpose |
|---|---|
| `<!DOCTYPE html>` | Declares a modern HTML document |
| `<html>` | Wraps the whole page |
| `<head>` | Holds page information |
| `<title>` | Sets the browser tab title |
| `<body>` | Holds visible page content |
| `<h1>` | Main heading |
| `<p>` | Paragraph |

## Opening and closing tags

    <p>Text goes here.</p>

- `<p>` opens the paragraph.
- `</p>` closes it.

## Remember

- HTML describes structure and content.
- CSS controls appearance.
- JavaScript adds behavior.
- The visible page content goes inside `<body>`.
